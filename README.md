# M. Furqan Shahid — Portfolio

Personal portfolio website showcasing GIS, remote sensing, and geospatial development projects.

**Live Site:** [https://furqan6701.github.io/](https://furqan6701.github.io/)

## About

This is the portfolio of **M. Furqan Shahid** — a GIS & Remote Sensing Specialist and Geospatial Developer.

## Tech Stack

- HTML5 (semantic)
- CSS3 (custom properties, no preprocessor)
- Vanilla JavaScript (ES6 modules)
- GitHub Pages (static hosting)

No frameworks. No build tools. Just clean, modular code.

## Project Structure

```
├── index.html              # Main HTML shell
├── sections/               # HTML templates for each section
├── css/                    # Stylesheets (variables, reset, components)
├── js/                     # JavaScript modules
│   ├── data/               # Structured data (projects, skills, etc.)
│   ├── components/         # Section renderers
│   └── utils/              # Utility functions
├── assets/                 # Images, fonts, documents
└── README.md
```

## Development

This site is developed incrementally with AI assistance. Each section is built independently:

1. Global HTML structure
2. CSS foundation
3. Navigation → Hero → About → Skills
4. Project data system → Project cards → Filtering
5. Experience → Education → Research → Contact
6. Animations → Responsive → Accessibility → Performance

## Deployment

The site is deployed via GitHub Pages. Push to the `main` branch to deploy.
